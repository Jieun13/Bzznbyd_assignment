# 아키텍처

## 전체 흐름

```
브라우저 → GET /Seoul
  └─ getServerSideProps
       └─ ApolloClient (SchemaLink, 인프로세스)
            └─ GraphQL 실행 엔진 (파싱 → validation → execution)
                 └─ resolvers.js → OpenWeatherMap REST API
       └─ cache.extract() → initialApolloState
       └─ props { city, initialApolloState, initialCurrentWeather, initialForecast }
  └─ SSR HTML 반환 (데이터 포함)
  └─ 클라이언트 hydration
       └─ ApolloClient (HttpLink + cache.restore(initialApolloState))
            └─ useQuery → 캐시 히트 → 네트워크 요청 없음

POST /api/graphql  ← 외부 접근용 엔드포인트 (curl, playground 등)
  └─ Apollo Server → resolvers.js → OpenWeatherMap REST API
```

OpenWeatherMap API Key는 서버(백엔드)에서만 사용 — 클라이언트에 노출되지 않음.

> SSR 단계에서 `getServerSideProps`는 SchemaLink로 구성된 Apollo Client를 생성해  
> 실제 GraphQL 실행 엔진(파싱·validation·execution)을 통해 쿼리를 처리한다.  
> 추출된 캐시(`initialApolloState`)는 클라이언트에 전달되어 `cache.restore()`로 복원되며,  
> `useQuery`는 복원된 캐시를 읽어 `/api/graphql`로의 재요청 없이 데이터를 반환한다.

## GraphQL 스키마

```graphql
type CurrentWeather {
  city:        String!
  country:     String!
  datetime:    String!   # ISO 8601 (응답 시각)
  timezone:    Int!      # UTC 기준 초 단위 오프셋
  temperature: Float!    # 섭씨
  feelsLike:   Float!
  tempMin:     Float!
  tempMax:     Float!
  humidity:    Int!
  description: String!
  icon:        String!   # OWM 아이콘 코드 (ex. "01d")
  windSpeed:   Float!    # m/s
  visibility:  Int!
  sunrise:     String!
  sunset:      String!
}

type ForecastItem {
  datetime:    String!   # ISO 8601 (UTC 기준, 표시 시 formatTime에서 timezone offset 재적용)
  temperature: Float!
  feelsLike:   Float!
  tempMin:     Float!
  tempMax:     Float!
  humidity:    Int!
  description: String!
  icon:        String!
  windSpeed:   Float!
}

type DayForecast {
  date:  String!            # YYYY-MM-DD (현지 날짜 기준 그룹핑)
  items: [ForecastItem!]!
}

type Forecast {
  city:       String!
  country:    String!
  population: Int
  days:       [DayForecast!]!
}

type Query {
  currentWeather(city: String!): CurrentWeather!
  forecast(city: String!):       Forecast!
}
```

## GraphQL 쿼리 (클라이언트 — `src/lib/queries.js`)

### 현재 날씨
```graphql
query GetCurrentWeather($city: String!) {
  currentWeather(city: $city) {
    city country datetime timezone
    temperature feelsLike tempMin tempMax
    humidity description icon windSpeed
    visibility sunrise sunset
  }
}
```

### 5일 예보
```graphql
query GetForecast($city: String!) {
  forecast(city: $city) {
    city country population
    days {
      date
      items {
        datetime temperature feelsLike
        tempMin tempMax humidity
        description icon windSpeed
      }
    }
  }
}
```

## OpenWeatherMap API

| 용도 | 엔드포인트 |
|------|-----------|
| 현재 날씨 | `GET /data/2.5/weather?q={city}&units=metric&appid={KEY}` |
| 5일 예보 | `GET /data/2.5/forecast?q={city}&units=metric&appid={KEY}` |

- `units=metric` → 온도 섭씨, 풍속 m/s
- 5일 예보는 3시간 간격 최대 40개 항목 반환

### 예보 날짜 그룹핑 로직 (`groupByDay`)
```
1. 현재 시각 기준으로 과거 항목 제외 (dt <= nowSeconds)
2. city.timezone 오프셋(초)을 적용해 현지 날짜(YYYY-MM-DD) 계산
3. 현지 날짜를 key로 배열에 push
4. 날짜 오름차순 정렬 → 최대 5일 slice
5. 각 날짜의 모든 항목을 ForecastItem으로 매핑
   (datetime은 UTC ISO 8601 저장 — 표시 시 formatTime에서 offset 재적용)
```

## 페이지별 데이터 페칭

| 페이지 | 방식 | 이유 |
|--------|------|------|
| `/` | 정적 (no fetch) | 도시 버튼만 렌더링, 외부 데이터 불필요 |
| `/[city]` | `getServerSideProps` (SchemaLink Apollo Client) | 항상 최신 날씨 필요, SSR |

### `[city].js` SSR 흐름
```
브라우저 → GET /Seoul
  → getServerSideProps({ params: { city: 'Seoul' } })
    → CITIES 검증 → 없으면 { notFound: true } (404)
    → makeExecutableSchema(typeDefs, resolvers)
    → ApolloClient(SchemaLink) 생성  ← HTTP 왕복 없는 인프로세스 실행
    → Promise.all([
        client.query(GET_CURRENT_WEATHER, { city }),   ← GraphQL 엔진 통과
        client.query(GET_FORECAST, { city })            ← GraphQL 엔진 통과
      ])
      → resolvers.js → OpenWeatherMap REST API
    → client.cache.extract() → initialApolloState
    → { props: { city, initialApolloState, initialCurrentWeather, initialForecast } }
  → SSR: _app.js → ApolloClient(HttpLink) + cache.restore(initialApolloState)
  → SSR: <CityPage> → useQuery → 캐시 히트, 렌더링
  → HTML 반환 (데이터 포함)
  → 클라이언트 hydration → useQuery → 캐시 히트 → /api/graphql 재요청 없음
```

## 코드 스플리팅

```
# .env.local
OPENWEATHER_API_KEY=your_api_key_here
```

- `resolvers.js`에서 `process.env.OPENWEATHER_API_KEY`로만 참조
