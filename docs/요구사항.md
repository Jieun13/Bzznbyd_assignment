## 페이지 구성

| 경로 | 설명 |
|------|------|
| `localhost:3000/` | 메인 페이지 — 도시 선택 버튼 |
| `localhost:3000/Seoul` | 서울 날씨 상세 페이지 |
| `localhost:3000/Tokyo` | 도쿄 날씨 상세 페이지 |
| `localhost:3000/Paris` | 파리 날씨 상세 페이지 |
| `localhost:3000/London` | 런던 날씨 상세 페이지 |

**동작 플로우**
1. 메인 페이지 접속
2. 도시 버튼 클릭
3. 해당 도시 상세 페이지로 이동

---

## 기능 요구사항

### OpenWeatherMap API
- **Current Weather API** — 특정 도시의 현재 날씨 정보
- **3-hour Forecast 5 days API** — 특정 도시의 5일 예보 정보

### 백엔드 (GraphQL)
- Next.js API Routes를 통해 GraphQL 서버 구현
- OpenWeatherMap API 호출은 백엔드에서 처리

### 프론트엔드
- Apollo Client로 GraphQL 쿼리
- 코드 스플리팅 적용
- Module CSS로 스타일링
- 피그마 디자인 기준으로 UI 구현

---

## 반응형 브레이크포인트

| 구간 | 동작 |
|------|------|
| `1280px 이상` | 레이아웃 화면 가운데 정렬 |
| `800px 이상 ~ 1280px 미만` | 레이아웃 width 100% |
| `800px 미만` | 레이아웃 고정 크기, 스크롤 처리 |
